Learn Java step by step, then read real Java projects.

JavaLearn is a small learning website. It has text lessons on the core topics of Java, and a projects section that loads Java programs directly from a GitHub repository, so you can read the source code of complete programs.

Projects come straight from GitHub

The project list is not typed into this website. JavaLearn reads the GitHub repository, finds the project folders, and shows each project's README details and Java source code. When the repository changes, the website shows the change.
