About JavaLearn

JavaLearn is a college Java project. It is a small website that helps beginners learn Java with plain text lessons and then read real Java programs.

What is on the website

  • Learn: text lessons from the introduction to Java up to JDBC. Each lesson has an explanation, syntax, examples and important points.
  • Projects: Java projects read automatically from a GitHub repository, with their descriptions and full source code.
  • Playground: write Java in the browser and run it. The code runs on an external, isolated service, not on this server.
  • Progress: lessons you finished and your quiz scores, saved in this browser only.

How the projects section works

GitHub is the source of truth. The Java backend asks the GitHub REST API for the list of files in the repository, finds the project folders, reads each README.md when it exists, and downloads the .java files. Nothing about the projects is typed into this website. If a project has no README, only its folder name and files are shown.

Built with

  • Java 21
  • Spring Boot and Spring MVC
  • Thymeleaf templates
  • Maven
  • HTML, CSS and a small amount of JavaScript (colours in code blocks)
  • The GitHub REST API

Privacy

JavaLearn is a learning project. It is designed to collect as little information as possible.

What JavaLearn does not do

  • There are no accounts, logins or sign-up forms.
  • The website does not use cookies, analytics or advertising.
  • The website does not ask for your name, email address or any other personal detail.

The project search

The words you type in the project search are sent to the JavaLearn server so it can filter the project list. The application does not store them.

Progress, Playground and X-Ray

Your lesson progress and quiz scores are stored in your own browser (localStorage). They are not sent to the server and do not sync between devices. When you click Run in the Playground, your code and input are processed by an external code execution service (by default the public Judge0 CE service). When you use X-Ray to step through execution, code is compiled and debugged locally on this server inside an isolated, separate JVM process subject to strict execution limits and timeouts. When you use the Code Quality Coach, your code is analyzed statically and checked against diagnostics without running untrusted code directly in the server application process. Do not submit private keys, credentials, or sensitive secrets in code.

GitHub

The JavaLearn server, not your browser, contacts GitHub to read the public project repository. Links such as “View on GitHub” open github.com, which has its own privacy policy.

Server logs

Like any web server, the computer or hosting service that runs JavaLearn may keep normal technical logs (for example the time of a request and the page requested). How long they are kept depends on where the website is hosted.
